# Automaticks.Reflection.Analyzers

Roslyn analyzers for `System.Reflection` usage.

Part of the [Automaticks Analyzers](https://github.com/Automaticks/Analyzers) family.

## Installation

```shell
dotnet add package Automaticks.Reflection.Analyzers
```

## Rules

| ID | Title | Category | Default Severity | Kind |
|---|---|---|---|---|
| `ATXRF030` | Reflection is forbidden | Reflection | Error | Analyzer |
